PRIME PASS

GTMで、氏名・電話・メールを引き継ぐ設定手順

テスト用のGTMコンテナ（ES CONの本物のコンテナは使いません）で、お試しください。

仕組み

  1. 確認画面が開く → タグ①が、画面の入力値（姓・名・電話・メール・関心プロジェクト・同意）を読み取り、ブラウザの一時メモ（sessionStorage）に置く。
  2. 完了画面が開く → タグ②が、そのメモをHTTPSで送る。使い捨ての「一時番号」が返る。
  3. 一時番号だけをつけて、アプリ（PRIME PASS）へ自動で移動。個人情報は、URLに載らない。

手順

  1. このフォームのページ上部の「GTMのコンテナID」に、テスト用のID（GTM-から始まる）を入れて保存。
  2. GTMで、トリガーを2つ作る：種類「カスタムイベント」、イベント名 pp_form_confirm_view と pp_form_thanks_view。
  3. タグを2つ作る：種類「カスタムHTML」。①に tag-confirm.js の中身を、<script> と </script> で囲んで貼り付け、トリガーは confirm_view。②に tag-thanks.js を同様に貼り付け、トリガーは thanks_view。
  4. GTMの「プレビュー」で、このフォームのURLをつないで、入力 → 確認 → 完了と進める。
  5. 確認用パネルに「①確認画面で読み取り」「②送信：成功」の記録が出て、5秒後にアプリへ移動すれば成功。

本番のフォーム（lmp1.net）に使うときの確認事項

  • 確認画面に、入力値が、同じ項目名（input_model[…]）の入力欄として残っているか（このまねフォームは、そう想定して作っています）。違う場合は、タグ①の読み取り部分だけ直します。
  • 確認画面・完了画面の表示を、GTMが検知できる方法（URL一致、または、ページ表示イベント）。
  • 本番では、タグ内のURL（INTAKE・APP）を、本番のものに差し替える。
  • GA4のイベント送信とは別に、このタグは、個人情報をGAへ送りません（GAに個人情報を送ると規約違反になるため、送信先は、PRIME PASSの受付窓口だけです）。
